# Адаптеры сайтов

Серверные адаптеры размещаются в `src/adapters/`. Для нового сайта используйте действующие `bilibili.js` и `douyin.js` как образцы интерфейса адаптера.

Для работы сайта в VOT также нужен клиентский Helper, зарегистрированный в реестре Helpers. Если Helper получает медиа через UMP, реализуйте регистрацию и проверку возвращаемого `mediaUrl`.

Для ссылок `.m4a`, `.mpd`, `.m3u8` проверьте `VOTClient.isCustomLink()`: ветка `requestVOT()` отправляет JSON, а UMP-перевод ожидает Protobuf Envelope. Добавляйте исключение только для нужного сайта и доверенного URL.

См. [интеграцию VOT](../../docs/VOT_CODE_CHANGES_RU.md).
