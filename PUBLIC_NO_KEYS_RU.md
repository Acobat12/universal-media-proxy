# Публичный сервер без API-ключей

Оба интерфейса — `/vot/*` и `/api/resolve` — работают без пользовательских ключей. Для установки запустите `sudo bash install.sh`. В конфигурации сохраняется только `TOKEN_SECRET`, необходимый для подписи ссылок `/media`.

Проверка: `curl -i https://media-proxy.mooo.com/health`. Проверка `/vot/video-translation/translate` с пустым JSON не подтверждает перевод, но не должна возвращать 401 из-за отсутствия ключа.
